SunSaver

SunSaver – Podium MET-pris (Meteorologisk Institutt)

SunSaver er en Android applikasjon utviklet i tverrfaglig teamarbeid som en del av emnet IN2000. Målet var å gi brukere innsikt i lønnsomheten ved å installere solcellepaneler på egen eiendom. Appen kombinerer værdata, strømpriser og takinformasjon for å vise realistiske beregninger av besparelser, tilbakebetalingstid og energiproduksjon.

Min rolle i prosjektet

I prosjektet var jeg primært ansvarlig for design og brukeropplevelse, men jobbet også tverrfaglig med utvikling i Android Studio (Kotlin og Jetpack Compose).
Mine nøkkelbidrag:

Samarbeid

Tverrfaglig samarbeid med utviklere for å sikre at designet ble oversatt nøyaktig til funksjonell kode.

Designprosess

Fokus på brukersentrert design gjennom innsiktsarbeid: deltok i workshops, analyserte spørreundersøkelser og hjalp med koding av data (affinity diagram).

Utvikling

Bidro med kode i Jetpack Compose, spesielt knyttet til layout, tekst, farger og navigasjon.

Live Demo / Appshowcase

Appen består av tre hovedskjermer:

  1. Hjemskjerm: Oversikt over lagrede solcelleanlegg, besparelser, produksjonsgrafer og tilbakebetalingstid.
  2. Opprett/rediger anlegg: Kartbasert funksjon der brukeren kan velge takflater, legge inn strømforbruk og få beregninger med støtteordninger.
  3. Infoskjerm: Brukerveiledning og generell informasjon om solenergi.

API er brukt: Met/Frost, HvaKosterStrømmen, Fjordkraft, Kartverket, Mapbox.

Verktøy

● Designverktøy

Figma, Canva & Lottie animasjoner

◆ Utvikling

Android Studio (Kotlin, Jetpack Compose), GitHub

▲ Smidig metodikk

ScrumBan med ukentlige sprinter og Kanban-board i GitHub

Refleksjon

Jeg lærte hvor viktig det er med tydelig kommunikasjon i tverrfaglige team, og hvordan iterativ design og testing kan gjøre en app mer brukervennlig. Selv om jeg startet som designer, endte jeg opp med å bidra bredt, noe som ga meg innsikt i både frontend koding, versjonskontroll og API integrasjon.
